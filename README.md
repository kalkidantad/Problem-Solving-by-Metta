This repository contains solutions to the exercises from Chapter 2 of the book "AI Algorithms, Data Structures, and Idioms in Prolog, Lisp, and Java", implemented using MeTTa.

Topics Covered
1. Relational Database Creation: Designing and querying relational databases.
2. Membership Checking: Techniques for verifying element existence in datasets.
3. Identifying Unique Elements: Extracting distinct elements from lists.
4. Counting Elements: Methods for counting occurrences of elements.
